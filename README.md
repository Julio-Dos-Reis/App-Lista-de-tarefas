Um Aplicativo de lista de tarefas utilizandO HTML5, PHP Bootstrap5, JS e Mysql
Basicamente, para esse aplicativo funcionar bem é preciso um banco de dados criado no servidor, caso contrário não roda
Para realizar a configuração do seu banco dados você tem que acessar o arquivo conexao.php que tem nesse repositório.
